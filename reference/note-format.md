# Note format contract

What `lint_note.py`, `check_snippets.py` and `build_pdf.py` enforce. Both tiers. The markdown is the source;
the **PDF is the deliverable** and is built from it. Follow this exactly; deviations break the build.

## 1. Files and names

| Thing | Pattern | Example |
| --- | --- | --- |
| Note source | `notes/<tier>/NN-<slug>.md` | `notes/basic/02-compilation-and-the-stack-frame.md` |
| Figures (generated) | `notes/<tier>/figures/NN-<name>.png` | `figures/02-stack-frame.png` |
| Figures (class visuals) | `notes/<tier>/figures/NN-class-<slug>.jpg` (or `.png`) | `figures/02-class-stack-frame.jpg` |
| Index source | `notes/<tier>/README.md` (generated by `update_index.py`, do not hand-edit) | |
| Sidecars | `.notes-plugin-internal/work/meta/<tier>/<stem>.{coverage.json,visuals.json,checks.py,figplan.yaml,figures.py}` | |
| PDF | `{PREFIX}-{NN}-{slug}-{tier}.pdf` | `CPP-02-compilation-and-the-stack-frame-basic.pdf` |
| Index / compendium PDF | `{PREFIX}-00-index-{tier}.pdf`, `{PREFIX}-Compendium-{tier}.pdf` | |

`NN` is the zero-padded session number (the stable file id; display order is the profile's `order`); the slug is
kebab-case from the digest's `slug` (what was actually taught, not necessarily the syllabus title), **fixed at
first generation** and stored in the ledger (`.notes-plugin-internal/state.json`). A re-run revises the same file
(writers get it as `note_out`); only `/notes:lecture N --rename-slug <new>` changes a slug. One note per
(session, tier): two notes with the same `NN` in a tier, or any `NN<letter>-…` companion file, or a
`companion_of` front-matter key, is a lint and qa failure (`dup-session`, `split-note`). Both tiers share the slug. Previous/next
links in the meta block are generated by the builder from course order: never hand-write them.

## 2. Front matter (YAML, first thing in the file)

Basic:

```yaml
---
title: "Compilation and the Stack Frame"
session: 2
tier: basic
profile: cpp
date: 2026-08-22
duration_min: 120
sources:
  - "Memory_Layout_-_Class_Scaler_Academy.txt"
instructor_code: ["Lec-2/main.c", "Lec-2/demo.c"]
revision_minutes: 32
verified_as_of: 2026-10-03
---
```

Advanced adds (and `revision_minutes` is optional there):

```yaml
prerequisites: ["01-why-cpp-and-the-memory-hierarchy.md"]   # [] if none
```

- `date` is ISO `YYYY-MM-DD` (take the profile's session `date` when the transcript header is ambiguous).
- `instructor_code` is a list of repo-relative paths, or `[]` / `null` when the subject has none.
- `verified_as_of` is today's date (the run date). Advanced notes: it must equal the research dossier's.
- The builder renders the visible meta block from this and links the other tier's PDF when it exists.
  Do not write a hand-made meta block in the body.

## 3. Headings

- Exactly **one H1**: `# NN · Title`.
- H2/H3 are **auto-numbered** by the builder (`2.4`, `2.4.1`). Never type numbers into headings: `## 1. Foo`
  is stripped with a lint warning.
- **Never type the section sign anywhere.** The builder resolves pages by matching it. Refer to sections in
  words: "see 2.4".
- Required sections for the tier come from the profile (`tiers.<tier>.required_sections`); matching is a
  case-insensitive prefix. Closing sections (`closing_sections`) are excluded from prose counts.

## 4. Code

- Fenced with a language: ` ```cpp `, ` ```python `, ` ```bash `, ` ```text `. Lines at most 95 columns
  (warn above 95, error above 120). Wrap long commands with `\`.
- A **runnable** fence carries `{run}` and must be followed, within 2 lines, by a ` ```text ` block with
  the **real output**. Lines starting with `$ ` in the output block are treated as commands and ignored in
  the comparison.

````markdown
```cpp {run}
#include <iostream>
int main() { int qty = 3; std::cout << qty * 2 << '\n'; }
```
```text
6
```
````

| Info string | Meaning |
| --- | --- |
| `{run}` | compile + run with the profile's `snippets.<lang>` template, compare output to the next text block |
| `{run nocheck}` | compile + run, do not compare (platform-dependent output; the caption must name the source platform) |
| `{compile}` | compile only |
| none | display only (config, fragments the language cannot run alone) |

Command lines shown to the reader (`g++ -std=c++20 -O2 main.cpp -o main`) go in a `bash` fence or as a
`$ ` line inside the output block. Name the compiler/platform when output differs by platform.

## 5. Tables, diagrams, math, figures

- **Tables:** at most 9 columns, header row required, no merged cells. Keep cells short.
- **ASCII diagrams:** in ` ```text ` fences, at most 95 columns. Memory layouts get addresses and offsets.
- **Mermaid:** ` ```mermaid ` only if the tier has `diagrams: mermaid-ok`. Shallow (about 8 nodes).
- **Math:** `$inline$` and `$$display$$` only if the tier's `math: true`. A literal dollar sign is `\$`.
  When math is false, write formulas as code or plain text.
- **Figures** (see `figures.md`): a paragraph holding only the image; the quoted title becomes the caption.
  Two kinds, told apart by the caption's lead:

````markdown
![Stack frame of add()](figures/02-stack-frame.png "**Redrawn.** Each call pushes one frame. Read the
offsets from RBP: arguments sit above, locals below.")

![Board: call stack for main, f, g](figures/02-class-call-stack.jpg "**From class, 00:53:31.** The
instructor's stack drawing: main at the top, each call below it, the OS at the bottom.")
````

| Kind | File | Caption lead |
| --- | --- | --- |
| Class visual (a crop of a class frame) | `figures/NN-class-<slug>.jpg` or `.png` | `**From class, hh:mm:ss.**` then what to look at |
| Class visual from a slide page | `figures/NN-class-<slug>.jpg` | `**From the slides, p.N.**` then what to look at |
| Redraw of a class visual, or a corrected version | `figures/NN-<name>.png` | `**Redrawn.**`, or `**Redrawn, corrected.**` plus what changed |
| Generated figure (no class counterpart) | `figures/NN-<name>.png` | a bold takeaway sentence |

Local `.png` or `.jpg` under `figures/` only (class photos as JPEG keep the PDF small; generated figures
stay PNG). No external images, no SVG. Never write a bare screenshot of a terminal or editor: transcribe it
as a `text` or `cpp` fence. Every digest V-row (treatment other than `text`) must appear, and its figure
file(s) are recorded in the `visuals.json` sidecar (section 9).

## 6. Callouts

`> **Label:** text` (optional severity in parentheses for corrections). The builder maps the label to a
style class; unknown labels render as plain quotes, so use these:

| Label (case-insensitive prefix) | Class | Use |
| --- | --- | --- |
| Note | note | extra context |
| Gotcha | gotcha | compiles/runs and is still wrong; differs by platform |
| UB | ub | undefined behaviour (low-level subjects) |
| Quiz tip, Exam tip, Interview tip | tip | what the assessment baits |
| Perf reality, Market reality, Production reality, Deployment reality, Compute reality | reality | how it looks in industry |
| Class correction, Transcript correction, Class nuance | correction | verified error in class: said, actual, why |
| Repo note | note | instructor repo differs from the class (drift is expected; never a correction) |
| Builds on, Revisited, Recall | note | sweep-inserted cross-session links (inside `<!-- sweep:ID -->` markers) |
| Reconstructed | recon | audio lost; says what the text follows |
| Maths | maths | symbol-by-symbol reading of an equation |
| Paper | paper | citation with year/venue plus one-sentence contribution |
| Jargon | jargon | a term defined out of line |
| Gap fill, Beyond class | gapfill | Basic: content added beyond class (counted, at most 120 words) |
| Source, Sources, Revision time, Study time, Verified | meta | provenance lines |

The profile's `callouts:` map adds subject labels (for example `"Exam tip": tip`).
Correction severity: `> **Class correction (🔴 critical):** said → actual → why it matters.` The emoji
(🔴 🟠 🟡) is what the index parses; the word after it is free.

## 7. HTML and links

- Raw HTML only `<details><summary>`, `<br>`, `<sub>`, `<sup>`. Details are force-opened in the PDF.
  Use `<details>` for answers in Check yourself if you want the question visible first.
- **Sibling notes:** relative `NN-slug.md` links; the builder rewrites them to PDF names or anchors. Link
  forward and back freely; a dead link is a lint warning.
- **External links:** absolute `https://`. Advanced: only URLs that appear in the research dossier part G.
- No bare external images, no iframes, no scripts.

## 8. Check yourself and answers

Number the questions. Put each answer directly beneath, bold the answer line, and give the one-line reason:

```markdown
1. What does `sizeof(Order)` print for `struct Order { char side; double price; };` on x86-64?
   **Answer: 16.** `side` pads 7 bytes to align `price` to 8.
```

## 9. Sidecars (`.notes-plugin-internal/work/meta/<tier>/`)

**`<stem>.coverage.json`**: digest concept ids mapped to where the note covers them.

```json
{"C01": {"sections": ["Compilation pipeline"], "worked_examples": 1},
 "C02": {"sections": ["Stack frame", "Cheat sheet"], "worked_examples": 2}}
```

Both tiers: every digest concept with depth `explained` or higher appears with at least one example
(`worked_examples >= 1`, a figure counts). Basic must cover at least 95% of them, Advanced 100%.

**`<stem>.visuals.json`**: which figure(s) realise each digest V-row (the writer writes it; `class_figure.py`
batch mode and `lint_note`/`qa.py` read it).

```json
{"V01": {"files": ["02-class-call-stack.jpg"], "treatment": "embed"},
 "V02": {"files": ["02-class-stack-frame.jpg", "02-stack-frame.png"], "treatment": "both"},
 "V03": {"files": [], "treatment": "text"}}
```

`files` are names under `figures/`. Every V-row appears exactly once; `text` rows have `files: []` and are
transcribed in the body instead.

**`<stem>.checks.py`**: every computable claim. Run by `verify_numbers.py`, which injects `ok`, `close`,
`section`, `np`, `math`, `Fraction`, `Decimal`, so no imports are needed (but allowed).

```python
section("Order layout")
ok(24 == 8 + 8 + 4 + 4, "Order has 24 bytes before tail padding", "price,qty,id,side")
close(250.75 * 40, 10030.0, tol=1e-9, label="notional = price * qty")
```

**`<stem>.figplan.yaml`** (only when figures are allowed): the plan the figure-author executes.

```yaml
- name: 02-stack-frame          # NN-kebab, matches the PNG and the image line
  section: "Stack frame"
  purpose: "show where args and locals sit relative to RBP"
  kind: memory-strip            # memory-strip | bars | curve | diagram | grid | trace
  data: "add(5, 3): rbp-4 = x, rbp-8 = y; numbers from the worked example"
  size_in: [7.4, 2.8]
  caption_draft: "**Locals live below RBP.** ..."
  schematic: false
```

**`<stem>.figures.py`**: written by the figure-author; see `figures.md`.

## 10. Lint summary (what fails the build)

| Error | Typical cause |
| --- | --- |
| missing front matter key | forgot `verified_as_of` |
| section sign present | typed it in a heading or caption |
| H1 not `# NN · Title` | extra H1 or wrong dash |
| missing required section | profile `required_sections` |
| code over 120 cols / table over 9 cols | wrap; split the table |
| image not `figures/*.png` or `figures/*.jpg`, or file missing | wrong path |
| a digest V-row (treatment not `text`) has no figure | embed or redraw it (content failure) |
| `{run}` fence without an output block | add the real output |
| placeholder text | `TODO`, `TBD`, `XXX`, lorem, `[citation needed]` |
| mermaid/figures/math the tier forbids | profile `diagrams`, `figures`, `math` |
| gap-fill share over cap (Basic) | cut fills |
| coverage sidecar missing a digest concept | add it, or cover the concept |

Warnings (fix anyway): a class figure with no `From class, hh:mm:ss` caption, Basic prose under the word
minimum ("too thin"), a one-line concept ("thin coverage"), code 96-120 cols, hand-numbered headings, disallowed raw HTML, banned phrases
(Advanced), Going Deeper over 8 bullets, check-yourself count out of range, dead `.md` links, too few figures.
